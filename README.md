# 台灣產業登記分析

用經濟部商業司與財政部的政府開放資料，看台灣各行業**哪一年成立、哪一年退場、現在還剩多少家**。

**線上瀏覽**：https://kresselock.github.io/Taiwan_industrial_distribution

涵蓋約 106 萬家公司、137 萬家商業登記（行號），時間範圍 2013 年至今。

## 分頁

| 分頁 | 回答的問題 |
|---|---|
| 產業總覽 | 這個產業現在有多少家？每年新設與退場各多少？五年存活率、資本額中位數是多少？ |
| 世代存活分析 | 某一年成立的公司，之後每年還剩幾成？A 年到 B 年之間有多少存續、退場、新設？ |
| 進退場動態 | 進入率與退出率各是多少，產業是在擴張還是在洗牌？近五年每月的進出情形如何？ |
| 產業比較矩陣 | 把所有產業放在「成長 × 存活」兩軸上，哪些是又成長又耐活的賽道？ |
| 地理分布 | 各縣市的規模、成長、存活率與市場集中度（HHI） |
| 資本結構 | 資本額分布，以及資本厚度和存活率的關係 |

左側可篩選：登記別（公司／行號）、產業、縣市、觀察期間、營運狀態、資本級距。

## 指標怎麼算

| 指標 | 定義 |
|---|---|
| 某年底存活 | 已設立（設立年 ≤ 該年），且目前仍存續或消滅年晚於該年 |
| 五年存活率 | 2013 年起、且已成立滿 5 年的世代中，撐過第 5 年的比例 |
| 進入率／退出率 | 當年新設（或退場）家數 ÷ 前一年底存量 |
| 進出強度 | （新設＋退場）÷ 前一年底存量。擴張快或淘汰多都會讓它變高，要和進入率、退出率一起看 |
| 5 年 CAGR | 近五年存量的年複合成長率 |
| 實質營運率 | 登記存續的公司中，財政部稅籍為「營業中」的比例 |
| 停業率 | 登記存續的公司中，稅籍為「停業中」的比例 |
| 資本額中位數 | 存續公司資本額（大於 0）的中位數 |
| 中位存續年數 | 已消滅公司從設立到消滅的時間中位數 |

登記存續是商業司的登記狀態；營業中、停業、非營業是財政部的稅籍狀態，比較接近實際營運情形。停業是暫時狀態、可以復業，和解散是兩回事。

## 運作方式

網站是純靜態頁面，沒有後端。頁面在瀏覽器裡用 [DuckDB-WASM](https://duckdb.org/docs/api/wasm/overview) 直接查詢 `data/` 下的 Parquet 檔。第一次開啟需要下載約 15 MB 資料與查詢引擎，之後的篩選都在瀏覽器記憶體裡計算。

`data/` 下都是預先彙總好的統計表，不含任何個別公司的資料：

| 檔案 | 內容 | 用途 |
|---|---|---|
| `cube.parquet` | 登記別 × 產業 × 縣市 × 登記狀態 × 稅籍狀態 × 設立年 × 消滅年 × 資本級距 的家數與資本總額 | 大部分的計數與比率 |
| `firms.parquet` | 同上但不分產業、以公司去重 | 年度比較（一家公司只算一次） |
| `capdist.parquet` | 資本額的精確分布（金額 × 家數） | 資本額中位數 |
| `life.parquet` | 已消滅公司的存續天數分布 | 中位存續年數 |
| `monthly.parquet` | 近五年每月的新設與退場家數 | 月度進出圖 |
| `meta.json` | 年份範圍、建置日期、總家數 | 頁首與頁尾資訊 |

中位數無法從級距彙總還原，所以 `capdist` 和 `life` 保留了精確分布，算出的中位數和原始明細資料算出的完全相同。

## 本機預覽

頁面必須透過 http 開啟，直接雙擊 `index.html`（`file://`）無法載入資料：

```bash
python -m http.server 8080
```

然後開啟 http://127.0.0.1:8080 。

## 更新資料

替換 `data/` 下的檔案並推送到這個 repo，GitHub Pages 會在一兩分鐘內自動更新。

`.nojekyll` 不要刪。它會停用 GitHub 的 Jekyll 處理，避免資料檔被略過。

## 已知限制

- **2013 年是下限**：登記清冊最早只到 2013 年 2 月，更早年份的存量無法回推。
- **多選產業時，年度比較會重複計算**：一家公司可以登記多個營業項目。不選產業或只選一個產業時數字是精確的；同時選多個產業時，屬於其中好幾個產業的公司會被重複計入，頁面上會另外註明。產業總覽等頁面的家數本來就是「產業別登記筆數」，不選產業時的總數同樣會大於實際公司家數。
- **行號的資本額來自稅籍**：商業司沒有提供行號資本額，這裡用財政部稅籍登記的資本額補上；查無稅籍的行號不列入。
- **不含公司明細**：只提供彙總數字，查不到個別公司。明細含負責人姓名與地址，不適合公開。

## 資料來源與授權
