# 台灣產業登記分析

用經濟部商業司與財政部的開放資料，分析各行業「哪一年成立、哪一年退場、還存活多少家」。

**線上瀏覽**：https://<你的帳號>.github.io/<repo名稱>/

## 內容

| 分頁 | 看什麼 |
|---|---|
| 產業總覽 | 現存家數、逐年新設與退場、五年存活率、資本輪廓 |
| 世代存活分析 | 每個設立年份的世代逐年還剩多少家；任兩年之間的存續／退場／新設拆解 |
| 進退場動態 | 進入率、退出率、進出強度，以及近年的月度進出 |
| 產業比較矩陣 | 全部產業放在「成長 × 存活」兩軸上比較 |
| 地理分布 | 各縣市規模、成長、存活率與市場集中度 |
| 資本結構 | 資本級距分布，以及資本厚度與存活率的關係 |

篩選維度：登記別（公司／行號）、產業、縣市、營運狀態、資本級距、觀察期間。

## 怎麼發佈到 GitHub Pages

1. 在 GitHub 建一個新的 repository（公開）
2. 把**這個資料夾裡的所有內容**上傳到 repo 根目錄
   （`index.html`、`data/`、`README.md`、`.nojekyll`）
3. repo 頁面 → **Settings** → 左側 **Pages**
4. Source 選 **Deploy from a branch**，Branch 選 `main` + `/ (root)`，按 Save
5. 等一兩分鐘，網址會是 `https://<帳號>.github.io/<repo名稱>/`

> 若把 repo 命名成 `<你的帳號>.github.io`，網址就是 `https://<你的帳號>.github.io/`（沒有子路徑）。

`.nojekyll` 不要刪，它會停用 GitHub 的 Jekyll 處理，避免資料檔被略過。

## 資料

`data/` 下是預先聚合好的統計表，不含個別公司資料：

| 檔案 | 大小 | 內容 |
|---|---|---|
| `cube.parquet` | 9.0 MB | 產業 × 縣市 × 狀態 × 稅籍狀態 × 設立年 × 消滅年 × 資本級距 的家數與資本總額 |
| `monthly.parquet` | 1.4 MB | 2019 年起的月度新設／退場家數 |
| `meta.json` | <1 KB | 年份範圍與建置日期 |

頁面用 [DuckDB-WASM](https://duckdb.org/docs/api/wasm/overview) 在瀏覽器裡直接查詢這些
Parquet，沒有後端。第一次開啟需要下載約 10 MB 資料與查詢引擎，之後都在本機記憶體運算。

## 資料來源與授權

- 經濟部商業司「[商工行政資料開放平臺](https://data.gcis.nat.gov.tw/)」公司登記、商業登記資料
- 財政部財政資訊中心「全國營業(稅籍)登記資料集」

以上均為政府開放資料，依「政府資料開放授權條款」第 1 版利用。

## 已知限制

- **2013 年是下限**：登記清冊最早回溯到 2013-02，更早年份的存量無法回推
- **中位數是推估值**：聚合資料無法精確計算中位數，改用資本級距線性插值
- **跨產業選取會重複計算**：一家公司可登記多個營業項目，同時選多個產業時會被重複計入
- **不含公司明細**：本版只有彙總數字，查不到個別公司（明細含負責人姓名與地址，不適合公開）
- **停業 ≠ 解散**：稅籍的「停業」是暫時狀態、可以復業，與商業司的「解散」是兩回事
